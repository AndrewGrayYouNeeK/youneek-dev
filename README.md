# youneek.dev

Homepage for [youneek.dev](https://youneek.dev), Andrew Gray's YouNeeK tools hub. Served by the `youneek-dev-home` Worker as static assets from `public/`.

Product subdomains such as CloudRipper and Death Terminal live in their own repositories.

## Deploy

From a machine logged in with Wrangler, or with `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` set:

```bash
npm run deploy
```
